# 🩺 Projet PFE – Système de prise de rendez-vous médical

## 📌 Description

Ce projet est une application web qui permet aux patients de prendre des rendez-vous avec des médecins en ligne facilement et rapidement.

## 🎯 Objectif

L'objectif est de digitaliser le processus de prise de rendez-vous médical afin de :

* Réduire le temps d'attente
* Faciliter la communication entre patient et médecin
* Améliorer l'organisation des consultations

## ⚙️ Fonctionnalités principales

* 👤 Inscription / Connexion des utilisateurs
* 🗓️ Prise de rendez-vous
* ❌ Annulation de rendez-vous
* 👨‍⚕️ Gestion des médecins
* 📋 Consultation de la liste des rendez-vous

## 🛠️ Technologies utilisées

* HTML
* CSS
* JavaScript

## 🚀 Comment utiliser le projet

1. Télécharger ou cloner le projet
2. Ouvrir le fichier `index.html`
3. Naviguer dans l'application
